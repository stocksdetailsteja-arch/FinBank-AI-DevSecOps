# EKS Banking Service with SRE

## Objective
Deploy a synthetic banking API on EKS with Helm, autoscaling, dashboards, alerts and a failure game day.

## Required evidence
- Architecture and threat model
- Reproducible infrastructure and application configuration
- CI/CD checks and immutable artifact identity
- Positive, negative, security and rollback tests
- Observability dashboard and failure diagnosis
- Cost shutdown record
- Interview explanation and lessons learned
