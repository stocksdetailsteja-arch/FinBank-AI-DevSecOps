# Banking Security Checklist

- [ ] Synthetic data only and documented classification.
- [ ] Authentication and object-level authorization tests.
- [ ] TLS at every external boundary and encryption at rest.
- [ ] Central key and secret management with rotation.
- [ ] Idempotency, replay protection and transaction limits.
- [ ] Immutable or protected audit evidence and time synchronization.
- [ ] Reconciliation for ledger and messaging paths.
- [ ] Segmented network and restricted egress.
- [ ] CI/CD short-lived identity and environment approvals.
- [ ] Source, dependency, IaC, image, API and secret scanning.
- [ ] Backup restore and access-revocation tests.
- [ ] AI data controls, prompt-injection tests and human approval boundaries.
- [ ] Legal and compliance requirements validated by qualified organizational stakeholders before real use.
