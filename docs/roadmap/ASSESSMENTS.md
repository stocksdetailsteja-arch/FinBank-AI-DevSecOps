# Assessments and Graduation Criteria

At the end of each phase:
1. Complete a closed-book concept explanation.
2. Rebuild one core lab from an empty directory.
3. Diagnose one injected failure using evidence.
4. Answer ten scenario questions aloud.
5. Review secrets, costs, screenshots and Git history.
6. Present one architecture trade-off and one rollback demonstration.

Final graduation requires a reproducible deployment, clean security scan or documented accepted risk, successful restore test, SLO dashboard, incident drill, AI evaluation report, cost cleanup and a ten-minute portfolio presentation.
