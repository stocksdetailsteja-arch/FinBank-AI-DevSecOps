# 🧪 Performance Testing Strategy

## Positive
Baseline and risk reports generate, bounded CPU test completes, decision record exists, and validator passes.

## Negative
Unsupported argument returns `64`; secret/HTML/blank-field scans pass; no background test remains.

## Comparison Discipline
Use the same workload, duration, environment, software version, sample interval, and business metrics before comparing results.

## Safety
No stress package, sysctl write, service restart, cloud resize, or production load generation.
