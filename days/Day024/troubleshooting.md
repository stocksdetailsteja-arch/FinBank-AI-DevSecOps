# 🚨 Advanced Recovery & Bootstrap RCA Playbook

> [!IMPORTANT]
> Each production scenario uses Symptoms, Evidence, Investigation, Root Cause, Fix, Rollback, Prevention, and Banking Impact.


## Scenario 1: Fresh EC2 Lacks Java

**Symptoms:** Recovery, toolchain, repository, or runtime validation fails.
**Evidence:** Doctor output, package version, service state, Git status, logs, checksums, endpoint response and source revision.
**Investigation:** Reproduce on a clean path and identify whether the failure belongs to the host, repository, tool installation, configuration, data, secret source or application lifecycle.
**Root Cause:** Record the proven dependency, permission, version, state or documentation defect.
**Fix:** Apply the smallest versioned correction and rerun fresh-clone validation.
**Rollback:** Restore the last known-good commit, tool version or host image.
**Prevention:** Pin or document versions, keep installation idempotent, test clean clones, scan secrets and retain audited backups.
**Banking Impact:** Recovery failure extends outage, delays settlement, weakens audit evidence, or risks inconsistent data restoration.
