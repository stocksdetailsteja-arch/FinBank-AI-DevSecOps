# 🤖 AI-Assisted Recovery Review With Human Governance

```text
Role: Senior SRE, platform engineer, Java architect, security reviewer and banking continuity lead
Context: Sanitized repository tree, tool manifest, bootstrap logs, backup policy, restore evidence and application tests
Task: Identify missing recovery assets, unsafe assumptions, secret exposure, untested restore steps and Day120 integration risks
Constraints: No credentials, destructive commands, cloud changes, invented evidence or automatic approval
Output: Finding, evidence, impact, corrective action, verification, rollback, banking impact and owner
```

> [!WARNING]
> AI may organize recovery evidence, but cannot authorize data restoration, approve production recovery, retrieve secrets, or certify financial reconciliation.
