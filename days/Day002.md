## Hands-on lab
Create or modify a small, reproducible artifact that demonstrates linux architecture, shell and filesystem hierarchy. Validate it with the relevant command, test, plan, scan, metric, log, or health check.

### Lab workflow
1. Create a feature branch named `day-002-lab`.
2. Record prerequisites and expected output in `docs/labs/LAB_NOTES_TEMPLATE.md`.
3. Make the smallest safe change and inspect the diff.
4. Run positive, negative and recovery validation.
5. Deliberately introduce one safe failure, diagnose it from evidence, and restore service.
6. Run the AWS shutdown checklist when applicable.
