# 🤖 AI-Assisted Authorization Review

```text
Role: Senior payment architect, Java engineer, fraud reviewer, security reviewer and SRE
Context: Sanitized intent and authorization models, state contract, tests and recovery evidence
Task: Identify invalid transitions, concurrency risk, missing controls and audit gaps
Constraints: No real payment data, autonomous approval, posting, settlement, invented evidence or destructive changes
Output: Finding, evidence, risk, recommendation, test, rollback, banking impact and owner
```

> [!WARNING]
> AI cannot approve a payment, override fraud or sanctions controls, or certify financial correctness.
