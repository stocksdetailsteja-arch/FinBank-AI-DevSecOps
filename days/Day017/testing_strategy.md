# 🧪 Observability Testing Strategy

## Positive Tests
Baseline, governance, timeline, and decision reports generate; three synthetic events correlate; validator passes.

## Negative Tests
Missing timeline input returns `66`; secret/HTML/blank-field scans pass; no raw identity-bearing evidence exists.

## Pipeline Tests
Test canary delivery, queue backlog, destination outage, rate limits, retention, rotation, access, redaction, and recovery.

## Safety
No journal vacuum, forced rotation, service restart, retention change, package install, firewall change, or AWS resource creation.
