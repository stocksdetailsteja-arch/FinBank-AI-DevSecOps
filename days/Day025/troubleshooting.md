# 🚨 Advanced Customer Service RCA Playbook

> [!IMPORTANT]
> Each scenario follows Symptoms, Evidence, Investigation, Root Cause, Fix, Rollback, Prevention, and Banking Impact.


## Scenario 1: Known Customer Returns 404

**Symptoms:** Customer endpoint, status code, response body or regression checks fail.
**Evidence:** Request path, HTTP status, JSON body, service result, repository data, build revision and logs.
**Investigation:** Reproduce the exact identifier and isolate routing, parsing, lookup, serialization or data-boundary behavior.
**Root Cause:** Record the proven code or contract defect.
**Fix:** Correct the smallest responsible layer and rerun customer plus full regression tests.
**Rollback:** Restore the last known-good revision and restart through the root lifecycle.
**Prevention:** Add service tests, API contract tests, negative cases and authorization-safe response models.
**Banking Impact:** Incorrect customer identity can expose data, mis-associate accounts, disrupt servicing or weaken auditability.
