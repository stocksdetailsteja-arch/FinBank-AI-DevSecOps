# 🤖 AI-Assisted Customer API Review With Human Governance

```text
Role: Senior Java architect, banking customer-domain engineer, API security reviewer and SRE
Context: Sanitized source, customer API contract, tests, status codes, service boundaries and roadmap
Task: Identify layering defects, contract ambiguity, privacy risk, missing negative tests and migration risk
Constraints: No real customer data, identity inference, production authorization, invented behavior or destructive changes
Output: Finding, evidence, risk, recommended change, test, rollback, banking impact and owner
```

> [!WARNING]
> AI cannot decide customer eligibility, infer identity, approve KYC, authorize data disclosure or replace human privacy and compliance review.
