## Commit and Push

```bash
git diff --cached --check
git commit -m "feat(day025): customer service foundation"
git push -u origin day-025-customer-service-foundation
```

> [!IMPORTANT]
> Do not stage Java build output, runtime logs, PID files, local secrets or unrelated Day023 evidence changes.
