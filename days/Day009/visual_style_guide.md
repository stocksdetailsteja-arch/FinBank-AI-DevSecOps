# 🎨 GitHub Visual Quality Standard

## ✅ Rules
- GitHub-native Markdown only
- No raw or escaped HTML
- No external badges/images
- Full scripts, not snippets, in artifacts
- Single-line terminal-safe commands
- Normalized evidence and no trailing whitespace
- Exact screenshots and redaction
