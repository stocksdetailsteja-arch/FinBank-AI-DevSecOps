# 🎨 Premium GitHub Presentation Standard

## Required Visual Language
- strong H1/H2/H3 hierarchy
- navigational header on every content page
- frequent meaningful GitHub callouts
- architecture and decision Mermaid diagrams
- matrices for controls, risks, decisions, and validation
- exact evidence filenames and completion gates
- deep answers rather than one-line definitions

## Prohibited
Literal break tags, escaped HTML, placeholder prose, flat list-only pages, external badge dependency, weak interview answers, sensitive data, and partial script snippets.
