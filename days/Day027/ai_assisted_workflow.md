# 🤖 AI-Assisted Transaction Review With Human Governance

```text
Role: Senior Java architect, banking transaction engineer, ledger reviewer, API security reviewer and SRE
Context: Sanitized source, transaction contract, tests, money model, state and recovery evidence
Task: Identify layering defects, money risks, state ambiguity, privacy gaps and missing reconciliation tests
Constraints: No real transaction data, autonomous posting, production authorization, invented evidence or destructive changes
Output: Finding, evidence, risk, recommendation, test, rollback, banking impact and owner
```

> [!WARNING]
> AI cannot authorize or post financial transactions, declare ledger correctness, or replace reconciliation and human approval.
