# 🌿 Day 027 Git & Recovery Governance

## Approved Staging

```bash
git add finbank-app/src/com/finbank/TransactionService.java
git add finbank-app/src/com/finbank/FinBankApplication.java
git add days/Day027
git add evidence/day027
git add screenshots/labs/day027
git add scripts/day027
git add scripts/testing/test-all.sh
git add scripts/validation/verify-all.sh
git add templates/day027
git add config/day027
git add docs/progress/DAY027_COMPLETION_CHECKLIST.md
git add INSTALL_DAY027_V1_PREMIUM_FINAL.md
```

```bash
git diff --cached --check
git commit -m "feat(day027): transaction service foundation"
git push -u origin day-027-transaction-service-foundation
```

Do not commit build output, runtime logs, PID files, secrets or unrelated prior-day evidence changes.
