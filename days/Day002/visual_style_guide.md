## ✅ Rendering Rules
- GitHub-native Markdown only
- No raw HTML
- No escaped HTML entities
- No remote badges or external image dependency
- Mermaid text excludes decorative symbols for reliable parsing
- Commands remain in fenced Bash blocks
- No trailing whitespace
- Navigation is consistent across all documents
