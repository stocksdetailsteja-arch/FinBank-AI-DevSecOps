## Approved Staging

```bash
git add finbank-app/src/com/finbank/AccountService.java
git add finbank-app/src/com/finbank/FinBankApplication.java
git add days/Day026
git add evidence/day026
git add screenshots/labs/day026
```

```bash
git diff --cached --check
git commit -m "feat(day026): account service foundation"
git push -u origin day-026-account-service-foundation
```

Do not commit build output, runtime logs, PID files, secrets or unrelated prior-day evidence changes.
