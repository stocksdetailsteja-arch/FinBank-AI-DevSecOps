# 🚨 Advanced Account Service RCA Playbook

> [!IMPORTANT]
> Each scenario follows Symptoms, Evidence, Investigation, Root Cause, Fix, Rollback, Prevention and Banking Impact.


## Scenario 1: Known Account Returns 404

**Symptoms:** Account status, payload, lookup, balance or regression behavior is incorrect.
**Evidence:** Path, HTTP status, response JSON, service result, repository record, build revision and runtime log.
**Investigation:** Reproduce with the exact account identifier and isolate route parsing, lookup, serialization, money handling or ownership mapping.
**Root Cause:** Record the proven defect.
**Fix:** Correct the responsible layer and rerun account, customer and full smoke tests.
**Rollback:** Restore the last known-good revision and restart using the root lifecycle.
**Prevention:** Add contract tests, money invariants, ownership checks, authorization-safe DTOs and audit evidence.
**Banking Impact:** Incorrect account data can expose financial information, misstate balances or mis-associate customers.
